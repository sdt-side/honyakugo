# 翻訳語コンバータ

[日本語](README.md) | [English](README.en.md) | [한국어](README.ko.md)

Xで流行したミーム「翻訳語」——外国語（主に韓国語のカジュアルな投稿）を機械翻訳した
ような日本語の文体——に、通常の日本語を変換するための道具一式。

元ネタは2026年11月にバズった投稿と、全員が翻訳語で返すそのリプライ欄。
他人の投稿文そのものは著作権に配慮して掲載していない。

## 中身

- `STYLE.md` — 実例コーパスと文体ルールの分析（本体）
- `prompt.md` — LLMに貼るだけで翻訳語変換ができるプロンプト（男性版／女性版／英語圏翻訳風／丁寧め／英語版／韓国語版）
- `honyakugo.py` — 軽量ルールベース変換器（間投詞の付与、語彙置換、文末調整、ㅋㅋㅋ付与）
- `examples.md` — 変換例
- `corpus_en.md` / `corpus_ko.md` — 英語版・韓国語版の実例コーパス（検証は実例を貯めて寄せる方式）
- `corpus_ja.md` — 英語・スペイン語から日本語への自動翻訳の実例観察メモ

## 使い方

```bash
python3 honyakugo.py "わかります、私もよくあります"
# -> わかります、私もしばしば起こります、マジで。

python3 honyakugo.py --female --kkk "それは面白い"
```

本格的な変換（比喩の直訳化、主語の明示など文の作り替え）は `prompt.md` を
LLM（ChatGPT / Codex / Muse 等）に貼って使う。

## 文体の要点

1. 間投詞で始める（クソッ、／ハハ、／おい、）
2. 日本語なら省略する主語・対象を明示する
3. 比喩は直訳的で大げさに（体型を食べ物に例える類）
4. 文末は「〜なんだよ」「マジで〜わ」「〜だよな」
5. 硬い直訳語を1つ混ぜる（しばしば、実に）
6. ㅋㅋㅋ は任意
7. 自然な慣用句で上手くまとめない。敬語にしない。短く。

詳細は `STYLE.md`。

## ライセンス

ライセンスは設定していません。

## ChatGPT / Codex / Claude での使い方

- ChatGPT: `prompt.md` のプロンプトをそのまま貼り、変換したい文章を続けると翻訳語で返ってくる
- Codex: このリポジトリを繋げば、`STYLE.md` と `prompt.md` を読んで同じ変換ができる
- Claude: `prompt.md` のプロンプトを貼るか、このリポジトリを読ませれば同じ変換ができる
- よく使うなら、プロンプトをカスタムGPTの指示文やClaudeのプロジェクト指示に入れておくと毎回貼らなくて済む
