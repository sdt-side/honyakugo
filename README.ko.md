# 번역어 변환기

[日本語](README.md) | [English](README.en.md) | [한국어](README.ko.md)

일반적인 일본어를 X에서 유행한 밈 '번역어' — 외국어(주로 한국어의 캐주얼한 게시물)를
기계 번역한 듯한 일본어 문체 — 로 변환하는 도구 모음입니다.

2026년 11월에 화제가 된 게시물
("クソッ、街を歩いててたら自分だけ肉団子みたいな体型なんだよ。マジでバカげてるわ。")과
전원이 번역어로 답한 그 답글란이 원본입니다.

## 구성

- `STYLE.md` — 실제 예문 모음과 문체 규칙 분석 (본체)
- `prompt.md` — LLM에 붙여 넣으면 번역어 변환이 가능한 프롬프트 (남성판 / 여성판 / 영어권 번역풍 / 정중한 버전 / 영어판 / 한국어판)
- `honyakugo.py` — 간단한 규칙 기반 변환기 (감탄사 추가, 어휘 치환, 문말 조정, ㅋㅋㅋ 추가)
- `examples.md` — 변환 예시

## 사용법

```bash
python3 honyakugo.py "わかります、私もよくあります"
# -> わかります、私もしばしば起こります、マジで。

python3 honyakugo.py --female --kkk "それは面白い"
```

본격적인 변환(비유의 직역화, 주어 명시 등 문장 재구성)은 `prompt.md`를
LLM(ChatGPT / Codex / Claude 등)에 붙여 넣어 사용하세요.

## 문체의 요점

1. 감탄사로 시작한다 (クソッ、 / ハハ、 / おい、)
2. 일본어라면 생략할 주어와 대상을 일일이 명시한다
3. 비유는 직역적이고 과장되게 (고기만두 같은 체형)
4. 문말은 「〜なんだよ」「マジで〜わ」「〜だよな」
5. 딱딱한 직역어를 하나 섞는다 (しばしば, 実に)
6. ㅋㅋㅋ는 선택 사항
7. 자연스러운 관용구로 매끄럽게 정리하지 않는다. 경어는 쓰지 않는다. 짧게.

자세한 내용은 `STYLE.md`를 참고하세요.

## 라이선스

라이선스는 설정되어 있지 않습니다.

## ChatGPT / Codex / Claude에서 사용하기

- ChatGPT: `prompt.md`의 프롬프트를 그대로 붙여 넣고 변환할 문장을 이어 쓰면 번역어로 돌아옵니다
- Codex: 이 저장소를 연결하면 `STYLE.md`와 `prompt.md`를 읽고 같은 변환이 가능합니다
- Claude: `prompt.md`의 프롬프트를 붙여 넣거나 이 저장소를 읽히면 같은 변환이 가능합니다
- 자주 쓴다면 프롬프트를 커스텀 GPT의 지시문이나 Claude 프로젝트 지시에 넣어 두면 매번 붙여 넣지 않아도 됩니다
